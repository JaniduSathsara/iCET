# iCET – Institute of Computer Engineering Technology 🎓

Welcome to the iCET repository!

## 🏫 About iCET

**iCET (Institute of Computer Engineering Technology)** is an educational institute in Sri Lanka that focuses on IT and software engineering education. It aims to help students develop technical knowledge and practical skills for careers in the technology industry.


## 💻 Areas of Study

- Software Engineering
- Programming
- Web Development
- Information Technology
- Software Development Practices
